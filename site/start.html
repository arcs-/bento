Getting started

1. Install

npm install bento

Import it once, and hide the elements until they are defined:

import "bento"; :is(bento-group, bento-panel, bento-separator):not(:defined) { visibility: hidden }

2. Server rendering

To prevent layout shifts ensure bento.js is loaded as a blocking script in the <head>, so server-rendered panels are laid out before the first paint and hydration moves nothing. Serve it from your public folder, e.g. copied there on install:

"postinstall": "node -e \"require('fs').copyFileSync(require.resolve('bento'), 'public/bento.js')\""

3. A first layout

The group fills its parent's height. Padding goes on an element inside each panel, so the panel can collapse to 0.
