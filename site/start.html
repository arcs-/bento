Getting started

Install

npm install bento

How you load it depends on who renders the HTML:

Your app Load bento
Plain HTML a blocking <script> in the <head>
Server rendered: Next.js, Nuxt, Astro, … the same, served from your own origin
Rendered in the browser only: Vite with React or Vue, … import "bento" in your entry file

To prevent layout shifts ensure bento.js is loaded as a blocking script in the <head> whenever the HTML arrives already rendered: a plain script, not a module, async or defer. It brings its own styles and needs no CSP exception.

Plain HTML

Or copy node_modules/bento/dist/bento.js next to your pages and load that.

Server rendered
