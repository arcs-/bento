Getting started

Install

npm install bento

Load it blocking in the head

To prevent layout shifts ensure bento.js is loaded as a blocking script in the <head>. A plain script, not a module, async or defer; it brings its own styles and needs no CSP exception.

In Next.js, put it in the root layout's <head>, since beforeInteractive does not block. A page that loads it later hides the elements until then:

:is(bento-group, bento-panel, bento-separator):not(:defined) { visibility: hidden }

A first layout

The group fills its parent's height. Padding goes on an element inside each panel, so the panel can collapse to 0.
