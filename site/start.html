Getting started

Install

The package will be bento on npm. A CDN URL is not settled yet.

npm install bento

Load it blocking in the head

A plain script, not a module, async or defer, so panels lay out while the page is parsed. It brings its own styles and needs no CSP exception.

In Next.js, put it in the root layout's <head>; beforeInteractive does not block. import "bento" works for apps that render only on the client.

Loading it later

Then hide the elements until they are defined:

:is(bento-group, bento-panel, bento-separator):not(:defined) { visibility: hidden }
