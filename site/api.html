API reference

Every attribute is optional and has a property. A bad value falls back to the default.

<bento-group>

Attribute Default Meaning
orientation horizontal horizontal follows the writing direction, vertical stacks. Reflected.

<bento-panel>

Attribute Default Meaning
size fill Starting size, px or %
min 0 Smallest size; content never gets smaller
max none Largest size
collapsible off Snaps collapsed past halfway below min
collapsed off Starts collapsed
collapsed-size 0 Size when collapsed, for a rail
modal never Media query; while it matches, the panel is a drawer
aria-label none Also names the drawer
Property Kind Meaning
size live Size now; "" while filling. Writes before the first layout are the start.
collapsed live Collapsed now. Writes animate after user activation; on a drawer, opens or closes it.
defaultSize, defaultCollapsed starting state What double-click restores; writing sets the attribute
min, max, collapsible, collapsedSize, modal reflected "" or false when absent
Event Fires Cancelable
resize The user changed the size, at most once per frame no
resizeend A drag, key press or double-click is done no
beforetoggle Before a collapse or expand you did not write when the user caused it
toggle After it no

None bubbles. Toggle events are ToggleEvents with "open" and "closed". Nothing fires for your own writes or the first layout.

CSS Use
:state(collapsed), :state(modal) Live state
--bento-size, --bento-min, --bento-max, --bento-collapsed-size Read the starting attributes
--bento-backdrop Drawer backdrop color
transition-duration, transition-timing-function Toggle timing, default 0.2s ease

<bento-separator>

Attribute Meaning
aria-label, aria-labelledby Its name; required
aria-controls Picks the primary panel; write it for browsers without element reflection
tabindex Added as "0" when absent

Role, orientation and values go through ElementInternals. :state(dragging) matches while dragged. Keys are in the guide.

TypeScript

The types register the elements in HTMLElementTagNameMap and export BentoGroupElement, BentoPanelElement, BentoSeparatorElement, BentoToggleEvent and friends. bento/react adds JSX typings.
