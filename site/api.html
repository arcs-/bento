API reference

Three elements. Every attribute is optional and has a property. A bad value falls back to the default, and never breaks the layout.

<bento-group>

Lays out panels and separators. Groups nest. It fills its container's block size.

Attribute Property Default Meaning
orientation orientation, reflects horizontal horizontal lays panels out along the writing direction, vertical top to bottom. Any other value reads as horizontal.

<bento-panel>

The element you write. The group sets its size, which may become 0. It clips its content, which keeps at least min. Its content is a size container.

Attributes

Attribute Default Meaning
size fill Starting size, in px or % of the group's space. Without it, the panel shares the remaining space equally with the other panels without one.
min 0 Smallest size while dragging. Content never gets smaller than this; the panel clips it instead.
max none Largest size while dragging.
collapsible off Dragging below min holds the panel; past halfway to collapsed-size it snaps collapsed. Enter on the separator toggles it.
collapsed off Starts at collapsed-size.
collapsed-size 0 Size when collapsed, for example a rail. At 0 the content is hidden with display: none.
modal never A media query. While it matches, the panel leaves the group and shows as a modal dialog while not collapsed.
aria-label none Also names the dialog in modal mode.

Properties

Two properties are live state, like value and checked on an <input>. The rest reflect their attributes; strings read "" when the attribute is absent, as in HTML.

Property Type Kind Meaning
size string live, writable The live size in px or %; dragging writes px. "" while the panel fills. Writing it fires no event.
collapsed boolean live, writable The live collapsed state. Writing it animates like a toggle and fires no event. On a modal panel, false opens the sheet and true closes it.
defaultSize string reflects size The starting size.
defaultCollapsed boolean reflects collapsed The starting state.
min string reflects
max string reflects
collapsible boolean reflects
collapsedSize string reflects collapsed-size
modal string reflects

A live property is clean until the user or a property write changes it. While it is clean, a changed size or collapsed attribute applies to it, without animating. Double-click on a separator makes both clean again.

Events

All fire on the panel and none bubbles; listen on a parent in the capture phase. None fires when your code writes a property, and none for the first layout.

Event Interface Fires Cancelable
resize Event When the user changes the panel's size, directly or by pushing it, at most once per frame. no
resizeend Event When a drag or key press is done: pointer up or key up. no
beforetoggle ToggleEvent Before a collapse or expand your code did not write, including a group collapsing panels as it shrinks, entering modal mode and a modal panel closing. when the user caused it
toggle ToggleEvent After that collapse or expand. no

oldState and newState are "open" for expanded and "closed" for collapsed. Canceling a snap holds the panel at min.

Custom states

Selector Matches
bento-panel:state(collapsed) The panel is collapsed, by anyone, including its group.
bento-panel:state(modal) The panel's modal query matches, open or not.

CSS

Property Use
--bento-size, --bento-min, --bento-max, --bento-collapsed-size Read only. The panel's attributes as lengths, declared on every panel, so a nested one never inherits its parent's. An absent size or max is unset, so var() takes its fallback.
--bento-backdrop Set on the panel: the color behind it in modal mode. Default rgb(0 0 0 / 0.1).
transition-duration, transition-timing-function Set on the panel: how long and how its toggles animate. Default 0.2s ease. A duration of 0 turns the animation off.

<bento-separator>

The draggable line between two panels, with the ARIA role separator. It has no attributes of its own and reads these of yours:

Attribute Meaning
aria-label or aria-labelledby Its name. Required: bento cannot know a good label.
aria-controls The id of the neighbour it resizes, its primary panel. Without it, the primary panel is the neighbour with a size or collapsible, the later one on a tie. Write it for browsers without ARIA element reflection.
tabindex Added as "0" when absent; yours is never overridden. It is the only attribute bento writes.

Its orientation and values go through ElementInternals: aria-valuenow is the primary panel's share of the group, 0 to 100, between aria-valuemin and aria-valuemax. It stays next to a collapsed panel and hides next to a modal one.

Selector Matches
bento-separator:state(dragging) While the user drags it.

Input

Input Does
Drag Resizes the primary panel and pushes further panels down to their min. Snaps collapsible panels at halfway.
Arrow keys along the group 10 pixels, 100 with Shift. Snap as soon as they go below min.
Enter Toggles a collapsible primary panel.
Home, End Primary panel to its min, to its max.
Double-click Primary panel back to its default size and collapsed state.

TypeScript

The package's types register the elements in HTMLElementTagNameMap, so document.querySelector("bento-panel") is typed. It exports BentoGroupElement, BentoPanelElement, BentoSeparatorElement, BentoPanelEventMap, BentoToggleEvent, ToggleState and Orientation. bento/react adds JSX typings for React 19.
