API reference

Every attribute is optional and has a property. A bad value falls back to the default.

<bento-group>

Attribute Default Meaning
orientation horizontal horizontal follows the writing direction, vertical stacks. The property reflects it.

<bento-panel>

Attribute Default Meaning
size fill Starting size; panels without one share the rest
min 0 Smallest size; the content never gets smaller
max none Largest size
collapsible off Holds at min, snaps collapsed past halfway
collapsed off Starts collapsed
collapsed-size 0 Size when collapsed; above 0 it is a rail that keeps its content
modal never Media query; while it matches, the panel is a drawer
aria-label, aria-labelledby none Also name the drawer

Lengths are px or % of the group.

Property Kind Meaning
size live Size now, "" while filling
collapsed live Collapsed now; on a drawer, closed
defaultSize, defaultCollapsed starting state Read the starting state; writing sets the attribute
min, max, collapsible, collapsedSize, modal reflected "" or false when absent
Event Fires Cancelable
resize The user changed its size, directly or by pushing; at most once per frame no
resizeend A drag, key press or double-click reset is done no
beforetoggle Before a collapse or expand you did not write, a shrinking group's included when the user caused it
toggle After it no

None bubbles; a parent listens in the capture phase. Toggle events are ToggleEvents from "open" to "closed" or back. Nothing fires for your property writes, attribute changes or the first layout.

CSS Use
:state(collapsed), :state(modal) Match the live state
--bento-size, --bento-min, --bento-max, --bento-collapsed-size Read the starting state; setting them is not supported
--bento-backdrop Set on the panel, colors the drawer's backdrop
transition-duration, transition-timing-function Time toggles and the drawer's fade, default 0.2s ease

<bento-separator>

Attribute Meaning
aria-label, aria-labelledby Its name; required
aria-controls Picks the primary panel; needed in browsers without element reflection
tabindex Added as "0" when absent

It resizes its primary panel: the neighbour with a size or collapsible, the later one on a tie. :state(dragging) matches while it is dragged; its keys are on Accessibility.

Rules

Topic Rule
Starting state Set by the attributes, or by property writes before the first layout, as React makes; double-click restores it. A changed attribute applies to the live state only while neither the user nor a property write has changed it, and never animates.
Animation Toggles and snaps animate; drags, mounting and window resizes never do. Writing collapsed animates only once the user has interacted with the page, so corrections on load are instant.
Toggle timing The panel's transition-duration and transition-timing-function; any other transition on a panel animates drags too.
Sizes A drag keeps a panel's kind of size: px stays px, a flexible or % panel gets a %. One panel always fills. A shrinking group collapses collapsible panels from the end and expands them when space returns.
Content A panel's display, flex and grid settings, gap, alignment and overflow lay out and scroll its children. Padding and borders on the sides that collapse go on a content element inside, or the panel stops collapsing at them.
Layout Your flex or flex-basis on a panel overrides bento's layout. Margins on panels and separators are not supported; gap on the group is.
Container queries @container queries inside a panel must be unnamed.
Drawers collapsed = false opens one, and one shows at a time. Escape, back and a tap outside close it by collapsing, so beforetoggle can veto. Closing gives the page back at once: you can focus or scroll it while the sheet fades.
Drawer styles The panel's size, padding, background, border, radius and shadow style the sheet. The page behind is inert, so menus opened inside must render inside it.
React 19 Hydration does not attach custom elements' on* handlers (react#35446); add listeners through a ref, and render tabindex="0" on separators.

TypeScript

The types register the elements in HTMLElementTagNameMap and export them, such as BentoPanelElement and BentoToggleEvent; bento-panels/react adds JSX typings.
