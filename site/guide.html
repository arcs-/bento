Modal panels

While its modal query matches, a panel is a drawer: it arrives collapsed, collapsed = false opens it, and Escape, back or a tap outside close it. Open the filters on the phone, then switch to desktop:

Same markup: a sidebar on wide screens, a drawer below 480px.

Style the panel itself; its box styles go to the sheet. One drawer shows at a time.

Events

Event Fires Cancelable
resize The user changed the size, at most once per frame no
resizeend A drag, key press or double-click is done no
beforetoggle Before a collapse or expand you did not write when the user caused it
toggle After it no

Events fire on the panel and never bubble; listen on a parent with capture: true. Your own writes fire nothing. Cancel beforetoggle to keep unsaved work: type in the notes, then collapse them.

    Live state

    size and collapsed are live, like an input's value. The attributes, or writes before the first layout, are the starting state that defaultSize and defaultCollapsed read and double-click restores. Writing collapsed animates once the user has interacted with the page. The inspector shows both side by side for any panel you click.

    Styling

    The demos above show bento's default look. This one is themed: any rule of yours wins over bento's. The group is the box and each panel a dish, styled on the elements themselves; one content element per panel only carries padding. It restyles the separators, times a toggle with the panel's transition-duration, dims :state(collapsed), and styles the drawer and its --bento-backdrop below 560px.
