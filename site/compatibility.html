Content Security Policy

bento needs no exception in a Content Security Policy. Its styles are constructed stylesheets, adopted by each element's shadow root. They are CSSOM objects, not <style> elements or style attributes, so style-src does not apply to them: no nonce, no hash, no 'unsafe-inline'. The one script is a file you serve, so script-src 'self' covers it.
